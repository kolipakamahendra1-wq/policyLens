# API Usage Standard
Policy ID: ENG-API
Domain: api_spec

## 1 Specification
New external APIs must publish an OpenAPI specification before launch. (risk: low; evidence: api_spec)

## 2 Authentication and rate limiting
External APIs must require authentication and enforce rate limits. (risk: medium; evidence: api_spec)

## 3 Versioning
Breaking changes to an API must be released as a new version.
