# Data Classification Policy
Policy ID: DATA-CLASS
Domain: data_classification

## 1 Classification levels
Data is classified as Public, Internal, Confidential or Restricted. Customer information is Confidential at minimum.

## 2 Classification of new systems
Every new system or API that stores customer information must record a data classification and a named data owner before launch. (risk: high; evidence: data_classification)

## 3 Handling
Restricted data must not be copied to non-production environments. (risk: high; evidence: data_classification)
